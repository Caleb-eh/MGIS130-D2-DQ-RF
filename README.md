# MGIS130-D2-DQ-RF
App for a daily quote and a random fact.
Data Layer: Two APIs (quote API + random fact API)
Processing Layer: Fetch new content, handle API errors, cache results
UI Layer: Attractive display with refresh button, responsive layout
What Information Goes In: The category chosen by the user, the list of quotes/facts inputted, or a website for quotes and trivia/fun facts
What Do You Do With It: Generate a new quote or fact based on the category you choose
How Should It Look: Simple, clean, and easy to read; display the quote using an image of the artist or an image relating to the fact, with the actual phrase(s) made clear and in an appropriate size/font.
