# MGIS130-D2-DQ-RF

App for a daily quote and a random fact.

* **Data Layer:** Two APIs (quote API + random fact API)
* **Processing Layer:** Fetch new content, handle API errors, cache results
* **UI Layer:** Attractive display with refresh button, responsive layout

### Input & Functionality
* **What Information Goes In:** User category, quote/fact list, or website source.
* **What Do You Do With It:** Generate a new quote or fact based on selected category.
* **How Should It Look:** Simple, clean, and easy to read.
